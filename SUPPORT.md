# Support

leafread is a volunteer, single-maintainer project. There is no paid support
and no guaranteed response time.

## Where to get help

| I want to… | Go to |
|---|---|
| Ask a usage question, share a setup | [GitHub Discussions](https://github.com/cigan1/leafread/discussions) |
| Report a bug | [Issues](https://github.com/cigan1/leafread/issues) with the bug template |
| Request a feature | [Issues](https://github.com/cigan1/leafread/issues) with the feature template |
| Report a security problem | [SECURITY.md](SECURITY.md) — privately, not in an issue |

## What to include in a bug report

- `leafread --version` and your OS/terminal (e.g. "iTerm2 3.5 on macOS 15",
  "Windows Terminal", "tmux 3.5 in kitty"),
- the exact command you ran, including flags,
- a minimal Markdown snippet that reproduces the problem,
- the output you expected versus what you saw (a screenshot helps for TUI
  layout issues).

## Scope of support

We are happy to help with:

- installation and build problems,
- rendering bugs with a reproduction,
- questions about flags and keybindings,
- terminal compatibility issues (graphics protocols, colors).

We cannot promise to support:

- custom terminal configurations we cannot reproduce,
- Markdown dialects outside CommonMark + GFM,
- use of leafread as a library (its internals are not a stable API yet),
- backports to older releases.
